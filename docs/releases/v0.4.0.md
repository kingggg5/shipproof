# ShipProof v0.4.0 — public beta

ShipProof now has a complete, inspectable path from an intentionally vulnerable API to a passing evidence gate.

## Highlights

- Five-finding FastAPI before/after demo with exact contract tests.
- Reusable composite GitHub Action and pre-commit hook.
- Repository policy through `.shipproof.yml` and `shipproof check`.
- Node.js, Python, secure, and performance regression fixtures.
- Python branch-coverage and Node core-coverage gates.
- Scanner self-benchmark with time, throughput, and peak-RSS budgets.
- JSON Schema contracts, SARIF, deterministic capacity-to-k6 export, and optional read-only MCP tools.

## Compatibility

- Node.js 20 or newer for the CLI.
- Python 3.10 or newer for scan, policy, budget, capacity, and MCP evidence tools.
- Config schema version `1` and evidence envelope `1.0`.

This is a public beta. Pin the release commit SHA for immutable CI usage. Stable CLI and schema compatibility guarantees are planned for v1.0.0.
