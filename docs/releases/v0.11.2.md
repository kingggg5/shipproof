# ShipProof v0.11.2 — Generated SARIF Coverage

ShipProof v0.11.2 is a patch on v0.11.1. The default workflow remains read-only, offline, deterministic, and dependency-free. This release does not change the 635-rule public catalog.

## Highlights

- Generated `.sarif` reports are recognized assets, not unknown binaries. A leftover GitHub Action or CLI report in the workspace no longer fails the completeness gate, and finding snippets inside that report are not re-scanned as source. All 635 executable scanner rules remain under the machine-readable assurance contract.

## Compatibility

Exit codes, public commands, and v1 evidence schemas are unchanged from v0.11.1.

## Verification

The release must pass `npm run check`, the direct high-severity self-scan, and the GitHub Release workflow on the immutable `v0.11.2` tag.
