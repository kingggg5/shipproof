# ShipProof v0.11.1 — Linux Host PATH and Research Coverage

ShipProof v0.11.1 is a patch on v0.11.0. The default workflow remains read-only, offline, deterministic, and dependency-free. This release does not change the 635-rule public catalog.

## Highlights

- Host PATH resolution follows symlinks such as Linux `python3` and then requires the canonical target to be a regular executable outside the repository. Repository-controlled PATH parents and in-repo implants are still rejected.
- Conventionally ignored trees, including `research/`, no longer fail the completeness gate when a Git-index hatch re-enters an oversized catalog. Selected application source that exceeds the size cap still makes coverage incomplete. All 635 executable scanner rules remain under the machine-readable assurance contract.

## Compatibility

Exit codes, public commands, and v1 evidence schemas are unchanged from v0.11.0.

## Verification

The release must pass `npm run check`, the direct high-severity self-scan, and the GitHub Release workflow on the immutable `v0.11.1` tag.
